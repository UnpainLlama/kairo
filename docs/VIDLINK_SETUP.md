# VidLink integration retired

VidLink is not used by Kairo and is not an available fallback for Movies playback.

CineSrc is now Kairo's **only Movie playback provider**. The current integration, URL format,
iframe message validation and troubleshooting steps are documented in
[docs/CINESRC_SETUP.md](CINESRC_SETUP.md).

This file is retained as a documentation pointer so older references do not lead to
instructions for a provider that is no longer part of the application.
