# VidLink integration retired

VidLink is not used by Kairo and is not an available Movie playback fallback.

CineSrc is Kairo's **only Movie playback provider**. The current URL format, iframe message handling and troubleshooting steps are documented in [CINESRC_SETUP.md](CINESRC_SETUP.md).

This file is retained as a pointer so older references do not lead to instructions for a provider no longer used by the application.
