# Artwork drop zone

Add original, commissioned, licensed, or otherwise authorized assets here. Suggested folders:

- `characters/` — transparent PNG/WebP character cutouts for hero/editorial layouts.
- `posters/` — portrait key art (2:3).
- `banners/` — landscape art (16:9 or 21:9).
- `avatars/` — user-uploaded or user-selected avatars.

For each asset, keep a small manifest with filename, creator/provider, source URL if applicable, license/permission basis, allowed use, and attribution requirements. Do not commit artwork whose usage rights are unknown. The bundled hero and poster visuals are CSS placeholders, not character assets.
